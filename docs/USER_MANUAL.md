# 扫码点餐系统 · 用户手册

一套面向餐饮门店的多租户扫码点餐系统：顾客扫码选菜下单，门店管理员实时接单排餐，超级管理员统一管理全部门店。

- **顾客端**：微信小程序（微信无感登录、桌号绑定、口味备注、追加菜品、取餐号）
- **门店管理端**：微信小程序（菜单、桌号、订单、排餐看板、营业状态）
- **超管 PC 后台**：Vue 3 Web 应用（门店/账号/二维码管理，可选）
- **后台**：Rust (axum + SQLx) + PostgreSQL，端口 8080

## 2. 环境准备与安装

### 2.1 下载代码

```bash
git clone https://github.com/bluebirds37/order_food.git
cd order_food
```

### 2.2 安装基础环境

| 软件 | 版本要求 | 下载地址 | 说明 |
|---|---|---|---|
| PostgreSQL | 14+ | https://www.postgresql.org/download/ | 数据库，默认示例使用端口 `15432` |
| Rust | 1.80+ | https://rustup.rs | 后端编译运行 |
| Node.js | 18+ | https://nodejs.org | 仅超管 PC 后台需要 |
| 微信开发者工具 | 最新稳定版 | https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html | 打开与预览小程序 |

### 2.3 初始化数据库

用 psql 或任意数据库工具连接 PostgreSQL，创建数据库：

```sql
CREATE DATABASE order_food;
```

> 后端启动时会自动执行 `backend/migrations/` 下的全部迁移脚本（建表 + 预置门店/管理员账号/桌号），**无需手工导入**。

### 2.4 配置后端连接

复制 `backend/.env.example` 为 `backend/.env` 并按需修改：

```env
DATABASE_URL=postgres://postgres:postgres@127.0.0.1:15432/order_food
# 微信小程序（可选：不配置 SECRET 时微信登录走开发模式，仍可完整体验）
WX_APPID=wx0ebd8a311374933d
WX_APP_SECRET=你的小程序密钥
```

全部配置项说明见项目 [README](../README.md#配置项)。

### 2.5 配置小程序后端地址

编辑 `miniprogram/app.js`：

- 本机模拟器调试：`http://localhost:8080/api`
- **真机预览**：改成电脑局域网 IP，如 `http://192.168.1.100:8080/api`，并确保手机与电脑同一 Wi-Fi、防火墙放行 8080 端口

## 3. 启动服务

### 3.1 启动后端

```bash
cd backend
cargo run
```

看到 `订单服务已启动 port=8080` 即启动成功（首次编译需数分钟）。

验证：浏览器打开 `http://localhost:8080/api/menu/overview?tenantCode=T001`，返回 JSON 即正常。

### 3.2 启动超管 PC 后台（可选）

```bash
cd admin-web
npm install
npm run dev
```

访问 `http://localhost:5173`，用超管账号登录，可管理门店、管理员账号与门店二维码。

### 3.3 打开小程序

1. 打开**微信开发者工具** → 导入项目 → 选择 `miniprogram` 目录
2. AppID 填 `wx0ebd8a311374933d`（或使用测试号）
3. **重要**：详情 → 本地设置 → 勾选「不校验合法域名」，否则无法访问 localhost
4. 点击「编译」，即可在模拟器中预览

### 3.3 内置演示账号

| 角色 | 账号 | 密码 |
|---|---|---|
| 超级管理员 | `superadmin` | `superadmin123` |
| 门店管理员（T001 食光小馆） | `tenantadmin` | `tenantadmin123` |

顾客端无需注册：进入点餐页即微信无感登录。

## 4. 快速上手：三步开店

1. **建门店**：超管登录小程序（管理员入口）→ 切换门店页创建/选择门店
2. **配菜单**：门店管理员 → 菜单管理 → 新增分类、新增菜品（上传图片、设置价格与口味选项）
3. **贴桌贴**：桌号管理中添加 A01/A02… 桌号，打印门店二维码贴到餐桌

顾客扫码即可开始点餐。

## 5. 顾客使用指南

### 5.1 扫码进入点餐页

顾客扫描餐桌上的门店二维码后直接进入点餐页，无需注册——微信无感登录自动完成，首次进入可一键绑定手机号。

![顾客点餐页](docs/images/menu-customer.png)

页面说明：

- **顶部店头**：门店名、营业状态、公告
- **桌号栏**：显示当前桌号，点击可弹出桌号选择弹层（或手动输入）
- **搜索框 + 分类标签**：按名称搜索菜品，或按分类快速跳转
- **加入按钮**：点击即弹出规格选择
- **底部购物栏**：已选菜品、合计金额、提交订单、历史订单

### 5.2 选择口味与备注

点击「＋ 加入」后弹出规格弹层：口味（单选）+ 备注（如"不要香菜"）+ 数量。

![口味与备注选择](docs/images/dish-options.png)

> 口味选项由门店在菜单管理中配置。同一菜品不同口味会在购物车中分行显示。

### 5.3 提交订单与取餐

确认桌号 → 提交订单。下单成功后系统给出**取餐号**，凭号取餐。

![订单详情与取餐号](docs/images/order-detail.png)

- 订单完成前（门店未"完成出餐/翻台"），可点击「追加菜品」，新菜品并入同一单
- 底部「历史订单」可查看全部消费记录

## 6. 门店管理员使用指南

### 6.1 登录管理端

管理员入口（点餐页登录入口或直接访问管理员登录页），输入账号密码登录后进入管理首页。首次进入需有门店上下文（从门店扫码或由超管授权的门店账号登录）。

### 6.2 数据看板

![管理首页](docs/images/admin-dashboard.png)

顶部实时展示今日营收、今日订单、在售菜品；下方为各管理入口。

### 6.3 排餐看板（核心）

![排餐看板](docs/images/admin-kitchen.png)

- 待出餐订单**按桌分列，从左到右按下单先后排列**——同桌优先出餐
- 每桌顶部高亮「合并出餐清单」：**菜品 + 口味 + 备注 完全一致的自动合并数量**（如首单微辣×2、加菜微辣×1 → 合并微辣×3，一次出餐）
- 每单操作：已支付 →「开始制作」→ 制作中 →「完成出餐」→ 移出看板
- 支持下拉刷新

### 6.4 其他管理功能

| 入口 | 说明 |
|---|---|
| 营业状态与介绍 | 开/关营业、店铺介绍、公告 |
| 菜单管理 | 新增/编辑/删除分类与菜品；上传主图与详情图；配置口味选项；上下架 |
| 桌号管理 | 卡片式增删改桌号，顾客点餐时下拉选择 |
| 订单管理 | 查看订单详情、更新履约状态、翻台（翻台后该桌进入新一轮消费） |

## 7. 超级管理员使用指南

超级管理员有两种工作台：**小程序内**（本节）与 **PC 后台**（`admin-web`，侧重门店开通、管理员账号、门店二维码）。两者用同一账号 `superadmin / superadmin123`。

### 7.1 无门店登录

超级管理员使用 `superadmin / superadmin123` 登录，**无需扫码**，登录后进入门店选择页。

![门店选择页](docs/images/admin-tenants.png)

### 7.2 切换与管理任意门店

点击门店卡片上的「进入管理」，即可像该店管理员一样管理其全部内容：菜单、桌号、订单、排餐、营业状态。管理首页顶部提供「切换门店」入口，可随时换店。已停用的门店不可进入。

## 8. 常见问题 FAQ

**Q1：小程序请求一直超时/无响应？**
确认开发者工具勾选「不校验合法域名」；真机预览需将 `app.js` 的 baseUrl 改为电脑局域网 IP 并保证同网段。后端请求超时已设为 10 秒，超时会明确提示。

**Q2：微信登录报错或手机号绑定失败？**
未配置 `WX_APP_SECRET` 时走开发模式（可用但非真实微信身份）；个人小程序可能无 `getPhoneNumber` 权限，绑定失败时可手动输入手机号。

**Q3：提交订单提示"请先选择桌号"？**
点击点餐页顶部桌号栏，从门店配置的桌号列表中选择即可。

**Q4：排餐看板看不到订单？**
看板只显示「已支付」和「制作中」的订单；完成出餐后订单移出看板，可在订单管理查看历史。

**Q5：顾客能往已完成的订单加菜吗？**
不能。追加菜品仅在同一轮消费内有效；管理员点击「翻台/完成出餐」后即视为新一轮。

**Q6：数据库端口必须是 15432 吗？**
不是，示例使用 15432。修改 `.env` 中 `DATABASE_URL` 为你的实际连接串即可。
